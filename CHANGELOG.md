# Сходка — что мы сделали с приложением

Голосовой чат для своей компании: общий чат и личка, голосовая комната, шумоподавление,
демонстрация экрана, свой сервер (на VPS или у хоста через Radmin VPN).

Этот документ — вся история работы над программой, от версии **1.11.2** (с которой мы начали)
до **1.23.0**. Две части:

| Период | Версии | Где лежит история |
|---|---|---|
| 14–30 октября 2026 | 1.11.2 → 1.20.4 | закрытый репозиторий, сохранён в `skhodka-git-1.20.4.bundle` (60 коммитов, метки v1.14.0-server, v1.15.0 … v1.20.4) |
| 9–13 ноября 2026 | 1.20.4 → 1.23.0 | этот репозиторий, [github.com/slabada/shodka](https://github.com/slabada/shodka) |

Новые версии — сверху.

---

## Коротко: главное по темам

- **Демонстрация экрана** — основная часть работы: размножитель на сервере (mediasoup, 1.16), захват и сжатие
  видеокартой «как OBS» (1.19), кодеки «H.264 — процессор» и «на нескольких ядрах» (1.17.5, 1.18.2), починка
  чёрной демки на Windows 11 24H2 (1.16.1), проверка картинки и «Отчёт о демке» с замерами у всех участников,
  «Чистка» лишней автоматики (1.17.0).
- **Голос** — звонок не рвётся при обрыве связи с сервером (1.15), «запись наперёд» и удержание концов слов,
  ровная громкость, RED (1.15.1), микрофон сам возвращается после отключения (1.17.3).
- **Сервер** — свой ретранслятор TURN, пакет для Windows-VPS с установщиком и окном с кнопками (1.14–1.18.1),
  админы (1.15.3, 1.18.0), резервная копия базы (1.17.3), голосования за кик и мут (1.22).
- **Развлечения** — музыка для всех (1.20.4+), звуки для всех с горячими клавишами и редактором (1.21),
  змейка (1.13.1).
- **Внешний вид** — дизайн «Шёлк» (1.12), 46 дизайнов (1.20.0), ещё 40 «Бархат» (1.20.4).
- **Сборка и обновления** — сборка установщика в GitHub Actions и автообновление из GitHub Releases (1.20.5).

## 1.23.1 — 14 ноября 2026

**Исправление: два человека на 1.23.0 могли не слышать друг друга.**

- В 1.23.0 сигнал «умею раздельные дорожки» (`caps`) уходил раньше предложения соединения. Вторая сторона
  из-за него тоже начинала предлагать, предложения сталкивались, одна сторона откатывала своё — и после отката
  Chromium переставал отправлять её голос. Соединение при этом было, а один другого не слышал. Со старыми
  версиями всё работало, поэтому «остальные его слышат».
- Теперь «умею» едет внутри предложения и ответа. Дорожки музыки и звуков добавляет только тот, кто предлагал
  первым, а отвечающий шлёт свои по ним же — встречных предложений нет, дорожек три вместо пяти.
- Голос переключается на «без музыки и звуков» только после того, как отдельные дорожки договорились.
- С 1.23.0 исправленная версия работает как со старой: музыка и звуки идут вместе с голосом. Раздельная
  громкость работает между двумя 1.23.1.
- Файлы: `renderer/js/rtc.js`.

## 1.23.0 — 13 ноября 2026

**Музыка и звуки для всех — отдельными дорожками, громкость у каждого слушателя своя.**

Раньше музыка и «звуки для всех» подмешивались прямо в голос: чтобы не слушать чужую музыку, приходилось
глушить человека целиком.

- Программы 1.23+ сообщают друг другу, что умеют раздельные дорожки (сигнал `caps`), и шлют три дорожки:
  голос без примесей, музыку и звуки. Дорожки музыки и звуков идут, только пока что-то играет.
- Друзьям со старой версией по-прежнему уходит всё вместе с голосом — у них ничего не меняется.
- Где регулировать:
  - правый щелчок по человеку → «Его музыка» и «Его звуки» (0–200 %, 0 — выключено);
  - Настройки → Звук → «Музыка для всех от друзей» и «Звуки для всех от друзей» — для всех сразу.
- У замьюченного голосованием глушатся и музыка, и звуки.
- Файлы: `renderer/js/rtc.js` (дорожки, `caps`/`fx`), `audio.js` (раздельные выходы микрофона),
  `soundboard.js`, `app.js`, `settings.js`.

## 1.22.0 — 12 ноября 2026

**Голосования за кик и мут командами в чате.**

| Команда | Что делает |
|---|---|
| `/kick ник [минут]`, `/кик` | голосование: выгнать из голосовой комнаты, вернуться нельзя N минут (по умолчанию 5, до 60) |
| `/mute ник [минут]`, `/мут` | голосование: без микрофона и без общего чата (личка работает); его голос глушится у всех |
| `/yes`, `/да`, `/за` · `/no`, `/нет`, `/против` | проголосовать (или кнопки «За» / «Против» на карточке над полем ввода) |
| `/cancel`, `/отмена` | отменить голосование — тот, кто начал, или админ |
| `/unmute ник`, `/unkick ник` | снять наказание раньше срока — только админ |
| `/help` | список команд; подсказка появляется и просто при наборе `/` |

- Голосуют все в сети, кроме того, против кого голосование. Нужно больше половины «за» и минимум два голоса;
  на голосование минута. Если «за» уже не набрать — заканчивается сразу.
- Одновременно не больше трёх голосований; один человек — не больше трёх в минуту.
- Наказания живут в памяти сервера: перезапуск сервера их снимает.
- Сервер объявляет возможность `votes`; на старом сервере команды отвечают «обновите хост».
- Файлы: `server/server.js` (голосования, наказания), `renderer/js/app.js` (команды, карточка, подсказки),
  `audio.js` (заглушение замьюченных).

## 1.20.5 — 9 ноября 2026

**Публичный репозиторий, сборка в облаке, автообновление.**

- Новый репозиторий [slabada/shodka](https://github.com/slabada/shodka). Первый коммит — версия 1.20.4 из
  установленной программы плюс **музыка для всех**:
  - свой плеер в голосовой комнате (`renderer/js/music.js`): файлы с компьютера (в том числе звук из видео)
    играют у вас и уходят в голос — их слышат все, бот на сервере не нужен;
  - «Из программы» — звук окна другой программы, включая свёрнутые (`main/musicapps.js`);
  - пока играет музыка, голос идёт с битрейтом 96 кбит/с; музыка приглушается, когда вы говорите.
- Сборка установщика (NSIS) в GitHub Actions (`.github/workflows/build.yml`): пуш в `main` — пробная сборка,
  тег `vX.Y.Z` — сборка и GitHub Release. Тег обязан совпадать с версией в `package.json`.
- Автообновление из GitHub Releases (`main/updater.js`, electron-updater). Работает только в программе,
  поставленной установщиком `Skhodka-Setup-*.exe` (рядом лежит `app-update.yml`); копия папки не обновляется.
- В этот репозиторий не перенесены тесты, проверки интерфейса, стенд замеров, пакет Windows-сервера,
  сборка mediasoup и документы — они остались в bundle 1.20.4 (см. «Что лежит только в bundle» ниже).

## 1.19.0 – 1.19.3 — 24–25 октября 2026

**«Видеокартой, как OBS».**

- **1.19.0** — новый способ показа: помощник `skh-videocap.exe` (C# + FFmpeg 8.1 LGPL: ddagrab,
  h264_nvenc / h264_amf) снимает и сжимает экран на видеокарте, а «Сходка» подставляет готовые кадры вместо
  своего сжатия (`renderer/js/gpucap.js`, `gpucap-worker.js`, `main/videocap.js`). Только весь экран, превью
  нет. Замер на RTX 2060: процессор «Сходки» у стримера 59 % одного ядра против 117 % обычным способом.
  Лицензия FFmpeg и источник сборки — в `native/bin/videocap`.
- **1.19.1** — срочная починка: в 1.19.0 интерфейс не загружался (комментарий сломал строку в
  `demoreport.js`). Добавлен тест «каждый файл разбирается без ошибок».
- **1.19.2** — пауза потока на сервере не выключает дорожки демки; обычный показ после показа видеокартой;
  смена экрана тем же способом захвата; понятное сообщение, если помощника нет; смена экрана не ломает демку
  зрителю через сервер.
- **1.19.3** — помощник переживает потерю экрана (смена полноэкранного режима, окно UAC) и пробует 30 с;
  в окне выбора у мониторов размер и пометки «основной» / «здесь «Сходка»»; проверка звука демки у зрителя
  и стримера; размножитель понимает H.264 кусками (сжатие на нескольких ядрах — и через сервер).

## Как устроена работа

**Сборка и выпуск** (с 1.20.5):

1. Поднять `version` в `package.json`.
2. Коммит и пуш в `main` — GitHub Actions собирает пробный установщик.
3. Тег `vX.Y.Z` (равный версии) и его пуш — сборка и GitHub Release. Установленные программы обновляются
   сами при следующем запуске.

**Запуск из исходников без Node.js на ПК.** Копия установленной программы без `app.asar`, в ней
`resources\app` — ссылка на папку репозитория, `node_modules` взяты из исходного `app.asar`. Запуск:

```bash
SKHODKA_EXPOSE=1 ./Skhodka.exe --profile=dev --remote-debugging-port=9229
```

- `--profile=имя` — отдельная папка данных: можно открыть две копии на одном ПК.
- Интерфейс проверяется через Chrome DevTools Protocol.
- Node для скриптов и проверки синтаксиса — сам `Skhodka.exe` с `ELECTRON_RUN_AS_NODE=1`.

**Совместимость.** Новые возможности включаются, только если их умеют обе стороны:

- сервер объявляет список `features` (`votes`, `moddel`, `logpull`, `sfu` …);
- программы договариваются сигналами (`caps`, `screen-meta`).

Старые версии при этом работают как раньше.

**Что лежит только в bundle 1.20.4.** Эти файлы не перенесены в публичный репозиторий:

| Что | Где в bundle |
|---|---|
| тесты | `test/*.test.js` — сервер, учётки, чат, файлы, ретранслятор, размножитель, «вместе», ZIP, синтаксис |
| проверки интерфейса в Chromium | `scripts/ui-check/*.py` |
| стенд замеров демки | `scripts/lab` |
| сборка mediasoup | `scripts/mediasoup` |
| упаковщик `app.asar` без npm | `scripts/asar.py` |
| пакет Windows-сервера | `deploy/windows`, `scripts/pack-server-win.py` |
| исходники помощников | `native/audiocap`, `native/videocap` |
| документы | `docs/PLAN-S.md`, `docs/PROVERKA-1.13.3.md`, `docs/IDEI-NEIROSETI.md` |
